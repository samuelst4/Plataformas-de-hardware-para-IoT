## 📋 Sobre o Projeto

Este repositório reúne documentações, esquemáticos e exemplos práticos para as principais **plataformas de hardware para Internet das Coisas (IoT)**. Ele serve como referência para estudantes, hobbystas e engenheiros no desenvolvimento de soluções conectadas.

---

## 🛠️ Plataformas Cobertas

| Hardware | Tipo | Conectividade | Aplicações Típicas |
| :--- | :---: | :---: | :--- |
| **ESP32** | Microcontrolador | Wi-Fi / Bluetooth | Sensores remotos, automação residencial, wearable IoT |
| **ESP8266** | Microcontrolador | Wi-Fi | Projetos de baixo custo, telemetria básica |
| **Raspberry Pi** | Microprocessador | Wi-Fi / Ethernet | Edge computing, gateways IoT, processamento local |
| **Arduino (com shields)** | Microcontrolador | Ethernet / LoRa / GSM | Prototipagem rápida, automação industrial leve |

## 🚀 Como Começar

### Pré-requisitos
Antes de executar os exemplos, certifique-se de ter instalado:
* [Arduino IDE](https://www.arduino.cc/en/software) ou [VS Code](https://code.visualstudio.com/) com a extensão [PlatformIO](https://platformio.org/).
* Driver da sua placa (ex: CP210x ou CH340 para ESP32/ESP8266).

### Clonando o Repositório
```bash
# Clone este repositório
$ git clone [https://github.com/samuelst4/Plataformas-de-hardware-para-IoT.git](https://github.com/samuelst4/Plataformas-de-hardware-para-IoT.git)

# Acesse a pasta do projeto
$ cd Plataformas-de-hardware-para-IoT
